# L3 — SEO

## Purpose
Titles, meta, social cards, and semantic structure for discoverability.

## Scope
Route `head` configuration and content semantics.

## Responsibilities
- Per-route title/description via route `head`.
- Canonical URLs when deployed.
- Meaningful headings; don't rely on canvas text alone.

## Dependencies
- `L2-TanStack-Router`
- `L2-Accessibility`

## Exclusions
- Analytics scripts (`L3-Analytics`).
- Deployment host headers (`L3-Deployment`).

## Usage Examples
- Replace starter title "TanStack Start Starter" with portfolio branding.

## Best Practices
- One H1 per page.
- Keep meta accurate to visible content.

## Common Mistakes
- Keyword stuffing.
- Missing Open Graph on share landing.
