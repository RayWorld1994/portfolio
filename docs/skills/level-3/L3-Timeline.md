# L3 — Timeline

## Purpose
Interactive About timeline milestones that illuminate on scroll.

## Scope
About/experience chronology UI.

## Responsibilities
Milestones: 2019 Angular → 2020 first pro project → 2022 enterprise → 2024 React/architecture → Future cloud architect.
Scroll triggers illuminate milestones and related network regions.

## Dependencies
- `L2-GSAP-Motion`
- `L2-Accessibility`
- Network extension concept from blueprint

## Exclusions
- Company node explorer details beyond timeline.
- Skills graph.

## Usage Examples
- Vertical timeline with scroll-linked active state.

## Best Practices
- Use semantic `<ol>`/`<li>` under the visuals.
- Pair with reduced-motion instant state.

## Common Mistakes
- Scroll-jacking the page.
- Dates without plain-text equivalents.
